# НарядAI

MVP системы выдачи и контроля производственных нарядов для кейса АО
«Костанайские минералы».

## Состав проекта

- `frontend` — Vue 3 PWA для мастера, исполнителя и руководителя;
- `backend` — FastAPI API, WebSocket и фоновые задания;
- `compose.yaml` — локальное окружение разработки.

## Быстрый запуск

1. Скопировать `.env.example` в `.env`.
2. Запустить `docker compose up --build`.
3. Открыть frontend: <http://localhost:5173>.
4. Открыть API docs: <http://localhost:8000/docs>.

## Первый сквозной сценарий

1. Мастер входит по ПИН-коду.
2. Создаёт и выдаёт наряд исполнителю.
3. Исполнитель принимает наряд и начинает выполнение.
4. Мастер видит изменение статуса по WebSocket.
5. Каждое действие сохраняется в журнале событий.
